# ALX Software Engineering

A single repository bringing together my work from the **ALX Software Engineering programme**: low-level C, Python, algorithms, back-end development, DevOps and a capstone project. Each folder was originally its own repository and keeps its full commit history.

**Author:** [Jim Chris](https://github.com/ghjimchris) · Accra, Ghana

## Capstone

| Project | Stack | What it is |
|---|---|---|
| [ALX-project](./ALX-project) | JavaScript (Node.js back end and front end) | A **Hospital Records Management System** built to address paper-based record keeping in remote parts of Ghana. |

## Low-level programming and algorithms (C)

| Project | What it covers |
|---|---|
| [alx-low_level_programming](./alx-low_level_programming) | The main C curriculum: variables, loops, functions, pointers, arrays, strings, debugging and more |
| [monty](./monty) | A Monty bytecode interpreter using stacks and queues (LIFO and FIFO data structures) |
| [sorting_algorithms](./sorting_algorithms) | Sorting algorithms in C, with Big O analysis: bubble, insertion, shell and others |
| [binary_trees](./binary_trees) | Binary tree operations: insertion, depth, ancestors, level-order traversal, rotations |
| [RSA-Factoring-Challenge](./RSA-Factoring-Challenge) | Factoring numbers as part of the RSA factoring challenge |
